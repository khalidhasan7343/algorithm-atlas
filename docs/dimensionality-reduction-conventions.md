# B5 numerical and API contracts

Float64 dense finite real X, shape (n,p), 1<=n<=512 (SVD); other inductive fits need n>=2 and 1<=p<=32, magnitude<=1e12; query rows<=4096, empty queries allowed for inductive transforms. Inverse transforms accept finite real latent coordinates without the original-feature magnitude cap, since projections can exceed original feature units; unresolved arithmetic still fails. Manifold embeddings require 3<=n<=128, output dimensions 1..3. Reject booleans/strings/complex/nonfinite data and invalid integer/seed parameters. Copy state, local RNG, atomic successful fits; invalid/failed refits retain prior state. Features are not automatically standardized.

Reduced Jacobi SVD uniformly rescales before column rotations and completes null bases deterministically. PCA centers and reuses SVD; variance ratios use scaled singular values. Physical variances may underflow for subnormal inputs. LDA normalizes globally before scatter, uses Sw + reg*I in normalized units and rejects unresolved singular Sw if reg=0. ICA whitens retained resolved directions and uses symmetric tanh fixed points; exhausted sweeps/ICA iterations raise ConvergenceError.

t-SNE and UMAP are transductive fit_transform only. They use bounded exact gradients with backtracking and expose optimization_status_, converged_, n_iter_, objective_history_, gradient_norm_; a finite optimization budget is a completed experiment, not a convergence guarantee. Unresolved line search raises ConvergenceError. t-SNE has no early exaggeration or momentum. Impossible perplexities below tied nearest-neighbor multiplicity are rejected.

UMAP uses exact Euclidean kNN excluding self, local_connectivity=1, target log2(k), directed exp(-max(0,d-rho)/sigma) and fuzzy union. Duplicate-induced unattainable targets use the documented sigma floor and saturated_rows_ diagnostics. Fixed a>0,b=1 rational output kernel, epsilon=1e-6 squared-distance smoothing, deterministic full unordered-pair cross-entropy and its attractive/repulsive gradient; no sampled negative edges or reference-coordinate parity. Disconnected graphs are supported by random initialization and repulsion.

Autoencoder: a single tanh bottleneck and linear decoder trained with MSE=sum residual²/(n*p), full-batch gradient descent with backtracking, optional linear encoder. Training-only mean/scale normalization retained for transform/inverse_transform. Fixed epochs expose honest optimization status as above. It is the only NumPy B7 canonical authorized here. C++ optional/absent; future deferred B7/AI and mandatory DSA policies remain unchanged.
