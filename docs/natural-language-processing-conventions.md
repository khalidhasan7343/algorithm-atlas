# B13 exact conventions

Owner MD.Khalid Hasan; MIT. Phase25 only, owner review pending. No runtime network, pretrained weights or framework delegates.

Text uses Unicode NFC then optional casefold, Unicode word runs and individual nonspace punctuation. Whitespace separates runs, sentence/document boundaries are explicit list elements, and no stop-word removal/stemming/subword model is implied. Whitespace/word splitting is not linguistically sufficient for every language. Strings <=4096 code points, tokens <=128 code points, <=128 tokens per document, corpus <=64 documents/2048 tokens. Fail explicitly rather than silently truncate. Shared vocabulary always reserves `<UNK>` at0, retains training words meeting min_count, caps vocabulary by descending count with lexical ties, then assigns retained words lexicographically. Vocabulary <=128 including UNK. Unknown words map to0; text vectorizers ignore UNK column. Empty text is allowed; empty corpus is rejected. No validation/test text enters fitted vocabulary/counts. Neural token-ID models have separate explicit PAD/MASK/BOS/EOS IDs and bounded sequences.

Batch1: BoW raw counts (optional binary), shared vocabulary; TF-IDF reuses canonical BoW, raw TF times log((N+1)/(df+1))+1, optional L2 normalization (zero vectors unchanged); add-k N-gram with k>0, order1..5, n-1 BOS contexts, one scored EOS, UNK predicted, BOS never predicted. Log likelihood and perplexity both include EOS; no cross-sentence counts or evaluation fitting.

Batch2: Word2Vec is sentence-local symmetric Skip-Gram Negative Sampling, fixed empirical negative draws from training unigram^.75 per fit, independent input/output embeddings and scatter-added repeated-ID gradients. GloVe uses positive cooccurrences only, inverse-distance context weights, weighted squared residuals and both vector/bias families; symmetric default and explicit left-context variant. Genuine bounded training and complete implemented parameter-group finite differences.

Batch3: BERT is a compact bidirectional token/position encoder with embedding parameters frozen at initialization with masked-language-model objective; GPT is decoder-only with strict causal attention, shifted next-token loss and bounded autoregressive generation. Genuine multi-head Q/K/V, residuals, layer norm, FFN and stacking. B7 layer normalization is reused unchanged. Educational **frozen random backbone, trainable linear vocabulary head only**; all head gradients checked, backbone freezing tested. This is neither pretrained language understanding nor full end-to-end pretraining. No NSP or segment embeddings claimed. BERT mask policy replaces all selected ordinary-token targets with MASK; only selected targets contribute to loss. Padding-key masks and invalid/all-masked handling are explicit. GPT future-token interventions must preserve earlier logits.

Pretokenized vocabulary mode uses `Vocabulary.fit_tokens(sentences)`: normalize each supplied original-case tokenizer unit with NFC/casefold while preserving its supplied boundary. This differs explicitly from raw-text mode,which casefolds before finding token runs. `encode`/`encode_tokens` keep the fitted mode;casefold-expanding tokenized inputs must use fit_tokens rather than silently map a training token to UNK. This matters for Unicode `İ`. POS uses the pretokenized path and never re-joins/re-tokenizes its tagged units.

Batch4: supervised smoothed HMM POS estimates initial/transition/emission counts separately per sentence and reuses unchanged B11 CategoricalHMM inference. B11 bounds <=8 labels/16 symbols (including unknown) apply. CRF is globally normalized linear-chain conditional likelihood with dense token features, emission weights, transitions and start/end potentials, stable forward/backward marginals, exact gradients and Viterbi. BIO NER is one explicit task baseline: training-only token/case/suffix features, canonical CRF with strict legal BIO start/transition masks, half-open token-offset spans and sentence-aware exact-span metrics. Gold tags are never inference features. Independent path enumeration/finite differences verify the models.

Batch5: CNF CYK recognizes terminal/binary productions with bounded cubic chart and reconstructs deterministic backpointers. Optional start-only epsilon requires start absent from binary right-hand sides. No automatic arbitrary-CFG conversion. Independent bounded derivation enumeration is the oracle.

All training/generation loops and allocations have further per-model bounds. Exact APIs, objectives, unsupported features and actual examples belong in each canonical lesson. Final B Track readiness is assessed separately from B13 implementation; DPO remains intentionally blocked and a separate comprehensive final ML audit is recommended, not executed or approved here.
