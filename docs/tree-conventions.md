# Tree representations and contracts

Phase 8 covers fourteen existing canonical topics after explicit Phase 7 approval. [Checkpoints](tree-algorithms-checkpoints.md) record sequential gates. Each lesson defines its own API; shared helpers perform validation/serialization, not the core algorithm.

Binary traversal nodes have IDs 0..n-1, values in [-10^9,10^9], and two child IDs or None/null (-1 in the C++ text CLI). A copied arena of arrays owns nodes, so even a 10000-node chain has no recursively owned destruction. n≤10000. Empty input requires absent root; a nonempty input requires an explicit valid root. A single connected acyclic tree with exactly one parent for each non-root node is required; shared children, duplicate child slots, cycles and disconnected nodes are rejected. Results contain node IDs, not values. Level order returns grouped levels. Input arrays are never mutated.

Rooted query trees use n≤10000 parent IDs with only root's parent absent. Validate references and whole-tree reachability. Child order is ascending ID, independently of parent-array ordering. LCA rejects absent/invalid IDs; identical nodes are valid. Binary lifting returns None/null for a missing k-th ancestor, with k in [0,10^18]. Euler Tour uses one preorder entry per vertex and exclusive subtree exit offsets: subtree(u)=order[tin[u]:tout[u]], not an Eulerian graph walk. No forest API is implied.

Fenwick and Segment Tree store at most 10000 integer values in [-10^9,10^9]. Prefix queries use exclusive end offsets and ranges are half-open [left,right), including empty ranges. Fenwick add accepts delta in [-2*10^9,2*10^9] and rejects an updated point outside the value contract; Segment Tree point set accepts a replacement value. Every finite sum has magnitude at most 10^13, safe in signed C++ 64-bit integers. Invalid updates validate before mutation.

Trie keys are ASCII lowercase a..z, length≤256; no normalization or Unicode equivalence is assumed. Empty word is valid; duplicate insert/erase-absent return false. Empty prefix is always present as the root path. Deletion prunes only unused nonterminal nodes. Limits are 10000 words and 100000 nodes, checked before a new insertion.

AVL, Red-Black, B-Tree and B+ Tree are ordered sets of at most 1000 integer keys in [-10^9,10^9]. Insertion/erase return bool; duplicate insertion and absent deletion return false. Root transitions and complete deletion are supported. C++ uses unique_ptr ownership; raw pointers, where present for B+ leaf links, are non-owning and maintained on split/merge. AVL and Red-Black logarithmic recursive helpers are safe within these caps. Null red-black leaves are black; implementation-specific left-leaning balancing is a genuine Red-Black representation. B-Tree t in [2,8] gives nonroot keys t-1..2t-1, internal child count keys+1. B+ leaves have t-1..2t-1 records; nonroot internal nodes have t..2t children; internal separator keys equal minima of children 1 onward. Only leaves store records, and leaf next pointers support half-open ordered ranges. Recursive balanced/multiway helpers have logarithmic depth.

Python APIs reject bool as integer and reject invalid types, dimensions and node references with ValueError. C++ typed APIs use checked constructors/methods and throw invalid_argument; CLIs reject malformed/missing/trailing integer tokens and exit 2. Python executable input is one JSON object. C++ uses strict decimal whitespace tokens; -1 denotes an absent node, and trie strings use '-' for empty. Every lesson gives the complete grammar. q≤1000 operations per executable request keeps diagnostic output bounded; reusable classes retain their stated size caps. Production operation bounds exclude test-only structural serialization and output snapshots, which cost O(n).
