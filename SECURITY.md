# Security policy

Algorithm Atlas is an educational project. Phase 0 provides repository tools and documentation; it does not contain algorithm implementations or production services.

## Report a vulnerability

Send suspected security vulnerabilities privately to **MD.Khalid Hasan** at [mdkhalidhasan7343@gmail.com](mailto:mdkhalidhasan7343@gmail.com). Include the affected file or command, relevant environment details, a minimal reproduction, and the potential impact. Do not send passwords, access tokens, private datasets, or unrelated personal information.

Please allow time to investigate before publishing details. The project does not currently promise a response deadline or a paid bounty. Ordinary correctness bugs and documentation issues can use the public issue templates when repository hosting is available.

## Development hygiene

Keep secrets and generated artifacts out of version control. Install development dependencies in an isolated environment. Review code and dependency instructions before executing examples. Future model and dataset downloads must be explicit, documented, and small enough for their intended use.
